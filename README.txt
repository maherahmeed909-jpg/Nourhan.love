موقع نورهان - ملفات البداية
===========================

1) افتح index.html وابحث عن:
   PASTE_YOUR_PUBLISHABLE_KEY_HERE
   واستبدله بمفتاح sb_publishable الخاص بمشروعك.
   لا تضع sb_secret في أي ملف داخل الموقع.

2) في Supabase > SQL Editor > New query:
   افتح schema.sql وانسخ محتواه ثم اضغط Run.

3) في Supabase > Storage:
   أنشئ bucket باسم noorhan-media واجعله Public.
   ثم شغّل سياسات التخزين الموجودة في schema.sql إذا لم تُنفذ بعد.

4) في Supabase > Authentication > Users:
   أضف مستخدم إدارة جديدًا يدويًا، واجعل البريد:
   admin@noorhan.local
   واجعل البريد Confirmed.
   كلمة المرور الأولية: 2008
   (يفضل تغييرها فور أول دخول من لوحة الإدارة إلى كلمة مرور قوية).

5) مهم: من Authentication > Providers > Email:
   عطّل السماح بالتسجيل العام (Allow new users to sign up) حتى لا ينشئ أي زائر حسابًا.

6) افتح index.html عبر استضافة مثل Netlify. لا تفتح الصفحة من ملف محلي فقط إذا منع المتصفح تحميل مكتبة JavaScript.

كلمات المرور:
- نورهان: 2020121 (بوابة عرض فقط وليست وسيلة لحماية محتوى سري).
- الإدارة: تتم المصادقة عبر Supabase Auth، وكلمة البداية 2008.
- بعد الدخول، يمكن تغيير كلمة مرور الإدارة من زر تغيير كلمة مرور الإدارة.

ملاحظات أمنية مهمة:
- مفتاح Publishable فقط في المتصفح.
- لا تستخدم أو ترفع مفتاح sb_secret إلى Netlify أو GitHub أو index.html.
- لأن كلمة مرور نورهان بوابة عرض على الواجهة، يستطيع شخص تقني تجاوزها وقراءة المحتوى العام. لا تضع معلومات خاصة أو حساسة في المحتوى العام.
- حساب الإدارة يجب أن يكون الحساب الوحيد الذي تسمح له بالتعديل. SQL يسمح لأي مستخدم Authenticated بالتعديل؛ لذلك عطّل التسجيل العام ولا تنشئ مستخدمين آخرين. ولأمان أعلى، يمكن لاحقًا تقييد السياسات على UUID حساب الإدارة فقط.
